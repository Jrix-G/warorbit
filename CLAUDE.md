# Token saving rules

Always minimize token usage.

Before coding:
- Inspect only necessary files.
- Use `rg`/`grep` before opening large files.
- Do not read generated files, build folders, `node_modules`, `dist`, `venv`, `.git`.

When responding:
- No long explanations.
- No markdown tables.
- No full file dumps.
- No recap unless asked.
- Give only modified files, command results, and next action.

When stuck:
- Ask one short question OR make the safest assumption.
