Rules:
- Be extremely concise.
- Do not explain obvious code.
- Do not summarize every file.
- Read only the files needed.
- Prefer `rg`/`grep` before opening files.
- Never paste full files unless requested.
- After editing, give only:
  - files changed
  - commands run
  - result
